# Program-using-binary-search-tree-
This project uses a Binary Search Tree (BST) to manage coupons based on their expiry dates. It allows users to insert coupon dates, delete all coupons within a specified date range, and display the updated tree using inorder traversal.

1. Problem statement:

Develop a coupon management application using a Binary Search Tree (BST) with expiry dates as keys. Delete all coupons within a specified date range and display the updated tree.

2.  Aim :

A) To implement a BST for managing coupon expiry dates.

B) To delete coupons within a given date range efficiently.


3.  Objectives :

A) Understand the concept of a Binary Search Tree.
Insert coupon expiry dates into a BST.

B) Delete coupons within a specified date range.
Display dates in sorted order using inorder traversal.


4.  Theory :

1.A Binary Search Tree is a hierarchical data structure.

2. The left subtree contains smaller keys.

3. The right subtree contains larger or equal keys.

4. In this project, coupon expiry dates are used as keys.

5. Inorder traversal displays expiry dates in sorted order.

6. Dates should be entered in YYYY-MM-DD format.


5.  Algorithm :

1. Start the program.

2. Create an empty BST.

3. Accept the number of coupons.

4. Insert each coupon expiry date into the BST.

5. Display the original BST using inorder traversal.

6. Accept the start date and end date.

7. Delete all nodes whose dates fall within the specified range.

8. Display the updated BST.

9. Stop the program.


6. Advantages : 

A) Organizes coupon expiry dates systematically.

B) Displays dates in sorted order.

C) Removes multiple expired-range coupons in one operation.

D) Demonstrates practical use of BST operations.



7.  Limitations : 

A) The program stores only expiry dates, not coupon codes or discount details.

B) Data is not stored permanently after the program ends.

C) An unbalanced BST may have slower operations.


8.    Real-World Applications : 

A) Coupon and voucher management systems.

B) Tracking promotional offer expiry dates.

C) Removing expired offers from online shopping applications.

D) Managing date-based records.


9.  Conclusion: 

A) The project demonstrates coupon expiry-date management using a Binary Search Tree.

B) It performs insertion, range-based deletion and inorder traversal.

C) It improves understanding of BST operations and their practical applications.
